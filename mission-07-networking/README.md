- Tools: VS Code,GitHub

## 4. My understanding
- A network connects devices so they can share data. LAN covers a small area, MAN a city, and WAN a large area.
- DNS works like a phone book. It changes a website name into an IP address.
- A router forwards data between networks.
- A protocol is a set of rules that devices follow to communicate.
- Data travels as small packets (packet switching).
- In client-server, the client (my browser) asks for a page and the server sends it back.
- Ping tells me if a website can be reached. nslookup shows the website's IP address and which DNS server answered.

## 3. Commands / tools used
| Command | Purpose |
|---|---|
|pwd | Shows current directory |
|ls | Lists files and folders |
|ls -lah | Detailed listing including hidden files |
|cd .. | Moves to parent directory |
|mkdir | Creates a folder |
|touch | Creates an empty file |
|cp | Copies a file |
|mv | Moves or renames a file |
|cat | Displays file contents |
|head | Displays first 10 lines |
|brew --version | Checks Homebrew version |
|brew list | Lists installed packages |

## 4. My understanding
I learned how to navigate directories, manage files and use Terminal commands. Flags modify command behaviour, while pipes connect commands. Package managers help install, update and remove software.
